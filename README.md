# Time-Series-Decomposition-of-Network-Traffic
## Overview
This project performs Time Series Decomposition on network traffic data to analyze Trend, Seasonal, and Residual components.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Jupyter Notebook

## All Project Files in one repo
- EXP-1.ipynb - Complete implementation
- output1.csv - Processed dataset

## Results
The project visualizes:
- Original Network Traffic
- Trend Component
- Seasonal Component
- Residual Component

## Future Improvements
- Forecasting using ARIMA/Prophet
- Anomaly Detection
- Real-time Network Traffic Analysis
